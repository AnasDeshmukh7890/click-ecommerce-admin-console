# CLICK Ecommerce Admin — starter setup

Requirements: Node.js 18+ and npm. Run `npm install`, `npm run dev`, and open the local address displayed by Vite. Use `npm run lint` and `npm run build` to validate the completed application.

Source data: `src/data/transactions.json`, `summary.json`, `navigation.json`. Brand assets and pixel design references are outside this starter in the input pack; logo is also mirrored in `public`.

The project opens to an initial guidance page by design. Implement the components required by `UI_REQUIREMENTS.md` before submitting. React dependencies are retrieved by npm during normal setup; no credentials are required.
